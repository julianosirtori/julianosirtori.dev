At work I use Windows with WSL, and every other option I tried made heavy use of RAM, which hurt my experience quite a bit.

My main requirements were:
* Switching quickly between different terminal sessions.
* Good WSL integration.
* Getting notified quickly whenever an agent got stuck.
* Having agent sessions back when I returned from work.

Browsing Twitter I found [herdr](https://herdr.dev/), and it does exactly what it promises:
> Herdr is where your coding agents live. However many you run, across however many projects, each in its own terminal. Walk away and they keep working. **Come back from any machine and they're where you left them.**

![herdr screenshot](/images/herdr-screenshot.png)

I can create different spaces, one per project, and inside each space I have tabs, one per feature.

So far it has served me well, but new tools show up all the time. It's not a silver bullet, and if you know a better one I'm open to suggestions :).
